Features

Everything a power user needs

Built for developers, writers, and researchers who want AI without the browser tab.

🫧

Bubble Interface

Frameless, rounded window with glassmorphism and drop shadow. Three sizes: Minimal, Compact, Extended. Stays out of your way until you need it.

🔀

Multi-Provider

Switch between OpenRouter, OpenAI, Anthropic, Google Gemini, and local Ollama models in one click. API keys encrypted with Windows DPAPI.

📎

File & URL Input

Drag & drop files or paste a URL — RobinHub fetches the page content automatically. Each attachment shows with a remove button.

📋

Prompt Templates

Point at any folder of .txt, .md, or .prompt files. Select a template; it becomes Part 1 of the prompt, your text becomes Part 2.

💾

Auto-Save History

Every response saved automatically with configurable file naming ({timestamp}_{model}) and subfolder patterns. Browse history from the sidebar.

🖼

Image & Video Gen

Toggle image or video generation per request. Model capability icons (🖼 🎬) shown inline in the model picker.

🔒

Security First

All keys encrypted via Windows DPAPI. Optional master password with strong enforcement (12+ chars, mixed case, digit, symbol). Change password without re-entering keys.

⌨️

Keyboard-First

Ctrl+Enter to send, Ctrl+1/2/3 for window sizes, Ctrl+T to pin on top, global hotkey to summon from anywhere.

🗂

Session Persistence

Conversations saved with provider, model, and message metadata. Context depth slider on the main UI. One click to start a fresh session.
